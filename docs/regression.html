How much will a room cost per night?

Linear regression and decision tree regression predict the average daily rate (ADR) of 85,582 paid bookings from attributes known at booking time.

Simple linear regression

With one feature, ŷ = b + w·x. Using total_guests (the attribute most related to ADR, r = 0.47):

ŷ = 39.51 + 33.95 × total_guests   →   3 guests: 39.51 + 33.95 × 3 = €141.37  ·  R² = 0.223

Seasonality (multiple linear regression)

With all 49 features the model explains 64% of the variance (10-fold CV: 0.645 ± 0.010). The weight of each month shows its price effect compared with April, all other features fixed.

Decision tree regression

A tree without limits reaches depth 50 and overfits (training RMSE €4.1, test €26.1). 10-fold cross-validation chooses max_depth = 16.
