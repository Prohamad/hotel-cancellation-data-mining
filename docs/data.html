Stage 01 · Data Understanding

119,390 bookings, 32 attributes, one question

The Hotel Booking Demand dataset records every booking of two hotels in Portugal that was due to arrive between July 2015 and August 2017. Each row is one booking; the class label is_canceled says whether it was canceled.

Missing values

Only four attributes have missing values. company is empty for 94% of bookings, so it cannot be used as it is.

Class label

In the raw file 37.0% of bookings are canceled. After removing exact duplicates the rate falls to 27.6%: most duplicates were canceled Non Refund bookings ().

ImplicationThe classes are imbalanced (≈ 72% / 28%), so accuracy alone is not enough — precision, recall and F1 are also reported.
