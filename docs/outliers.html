Stage 03 · Outlier Analysis

Which extreme values are errors, and which are real?

Four numeric attributes were checked with the IQR and Z-score methods. Each group of outliers was then evaluated: a valid observation is kept, a data-entry error is removed.

Two methods

IQR method

An outlier lies outside the "fences" built from the middle 50% of the data.

IQR = Q3 − Q1
outlier if x < Q1 − 1.5·IQR  or  x > Q3 + 1.5·IQR

Z-score method

An outlier is more than three standard deviations away from the mean.

z = (x − mean) / std
outlier if |z| > 3

Decision
