Basic concepts

An outlier is a data object that deviates significantly from the rest of the objects, as if it were generated by a different mechanism. Outliers are not the same as noise: noise is random error, while an outlier may be a real but unusual observation.

Global

Deviates from the whole data set. Example: a room rate of €500 per night.

Contextual

Deviates only given its context. Example: €200 is normal in August but unusual in January.

Collective

A group of objects that is unusual together, although each object alone may look normal.

For contextual outliers, the contextual attributes define the group (hotel, month) and the behavioural attribute is the one being tested (adr). The IQR method is nonparametric (no distribution assumed); the Z-score method is parametric (it assumes a roughly normal distribution).

Three methods

IQR method

An outlier lies outside the "fences" built from the middle 50% of the data.

IQR = Q3 − Q1
outlier if x < Q1 − 1.5·IQR  or  x > Q3 + 1.5·IQR

Z-score method

An outlier is more than three standard deviations away from the mean.

z = (x − mean) / std
outlier if |z| > 3

Histogram method

Split the values into bins; a value in a bin with very low probability is an outlier. Described in the next sections below the results.

Decision

FindingFor total_guests, Q1 = Q3 = 2, so the IQR is 0 and the IQR method flags almost 30,000 normal bookings. The Z-score was used instead. Only the 17 bookings with more than 5 guests are impossible values and were removed; all other extreme values, including the histogram and contextual ones, describe real customer behaviour (peak season, free or complimentary stays) and were kept.
